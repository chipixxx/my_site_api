# Использование API сервисов при разработке сайтов

Данный проект представляет собой образовательный веб-сайт, разработанный в рамках учебного задания. Главная цель проекта - доступно и наглядно объяснить базовые концепции работы с API в современной веб-разработке.

## Описание проекта
Сайт состоит из 8 семантически структурированных HTML-страниц и охватывает следующие темы:
- Что такое API и принцип клиент-серверного взаимодействия.
- Архитектурный стиль REST.
- Сравнение форматов обмена данными (JSON и XML).
- Обзор популярных веб-API (Google, Telegram, OpenWeather).
- Практические примеры работы с Fetch API в JavaScript.
- Основы безопасности (CORS, API-ключи, OAuth 2.0, Rate Limiting).

## Используемые технологии
- HTML5: строгая семантическая разметка (header, main, aside, article, footer).
- CSS3: адаптивный дизайн, использование CSS-переменных, Flexbox и CSS Grid.
- Cutestrap: легковесный CSS-фреймворк для аккуратной типографики и форм.
- JavaScript (Vanilla JS): функционал мобильного меню и автоматическая генерация оглавления на основе заголовков страницы.

## Инструкция по запуску
Проект представляет собой классический статический веб-сайт. Для его работы не требуется установка локального сервера или баз данных.

Локальный запуск:
1. Склонируйте репозиторий или скачайте архив с кодом.
2. Распакуйте архив в любую директорию.
3. Откройте файл index.html в любом веб-браузере. Навигация по страницам будет работать автоматически.
